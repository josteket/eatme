# 🍽 EAT ME — семейное меню (без глютена + ГСД)

Telegram Mini App для двоих: выбираем блюда → собираем **план еды** → приложение
считает КБЖУ и собирает **список покупок** → второй получает уведомление в Telegram
→ можно открыть рецепт и повторить заказ.

Все блюда — **строго без глютена** и с учётом **углеводной нагрузки при ГСД**
(гестационный диабет). Для целиакии опасные ингредиенты автоматически исключаются
из меню.

> ⚠️ Приложение помогает планировать питание и выбирать блюда. Оно **не заменяет
> врача**. Цели по углеводам, калорийности и контролю глюкозы определяет медицинский
> специалист.

---

## Что внутри

- **Backend:** Python + FastAPI + SQLite (один файл базы, без Docker)
- **Бот:** aiogram 3 — запуск Mini App и уведомления
- **Mini App:** чистый HTML/CSS/JS (без сборки) — открывается внутри Telegram
- **Данные:** 82 ингредиента с КБЖУ и глютен-статусом + 36 реальных рецептов;
  КБЖУ считается автоматически из ингредиентов
- **Тесты:** проверка расчёта КБЖУ, объединения списка покупок и защиты от глютена

Всё крутится в **одном процессе** на твоём ПК.

## Быстрый старт (Windows)

### 1. Установка

Нужен **Python 3.11+** ([python.org](https://www.python.org/downloads/), при установке
поставь галочку **Add Python to PATH**).

Дважды кликни **`install.bat`** — он создаст окружение, поставит зависимости и наполнит
базу блюдами.

### 2. Настрой `.env`

Открой файл `.env` в корне и заполни:

```env
ALLOWED_TELEGRAM_IDS=111111111,222222222   # твой ID и ID жены (через запятую)
WIFE_TELEGRAM_ID=111111111                  # ID жены (беременная, ГСД+целиакия)
WEBAPP_URL=https://твой-тоннель.trycloudflare.com   # см. шаг 4
```

**Как узнать Telegram ID:** запусти бота (`start.bat`), напиши ему `/id` — он пришлёт
твой ID. Или напиши боту [@userinfobot](https://t.me/userinfobot).

> 🔑 Токен бота уже вписан в `.env`. Так как он засветился в переписке —
> **перевыпусти его** в [@BotFather](https://t.me/BotFather) (`/revoke` → новый токен)
> и вставь новый в `.env`.

### 3. Запуск для Telegram (рекомендуется) — «в один клик»

Дважды кликни **`start-online.bat`**. Он сам:
1. поднимет туннель `cloudflared` (публичный HTTPS к твоему ПК),
2. подставит полученный адрес в `WEBAPP_URL` (правит `.env` автоматически),
3. запустит сервер + бота.

Когда в окне появится строка **«✅ ВСЁ ГОТОВО … Публичный адрес…»** — открой бота в
Telegram и нажми **/start**. Кнопка «🍽 Открыть меню» заработает.

> Держи это окно открытым, пока пользуешься приложением (в нём крутятся сервер и
> туннель). Адрес быстрого туннеля меняется при каждом запуске — это нормально, бот
> всегда берёт актуальный. Закрыл окно → приложение недоступно, просто запусти снова.

### Запуск только локально (для теста без Telegram)

Дважды кликни **`start.bat`** и открой `http://localhost:8080` в браузере
(работает в режиме `DEV_MODE=true`, без Telegram). Кнопка в Telegram при этом
запуске работать не будет — для неё нужен `start-online.bat`.

### 4. (Альтернатива) Туннель вручную

Telegram открывает Mini App **только по HTTPS**. Домашний ПК так просто наружу не
торчит, поэтому нужен туннель. Самый простой — **cloudflared** (бесплатно, без аккаунта):

1. Скачай `cloudflared.exe`:
   [загрузка для Windows](https://github.com/cloudflare/cloudflared/releases/latest)
2. Запусти (когда `start.bat` уже работает):

```bash
cloudflared tunnel --url http://localhost:8080
```

3. Он выдаст адрес вида `https://random-words.trycloudflare.com` — впиши его в
   `.env` → `WEBAPP_URL`, и **перезапусти** `start.bat`.

> Адрес быстрого туннеля меняется при каждом запуске. Для постоянного адреса можно
> завести бесплатный именованный туннель Cloudflare (нужен домен) — по желанию.

### 5. Кнопка запуска в Telegram

- Напиши боту `/start` — он пришлёт кнопку **🍽 Открыть меню**.
- Чтобы кнопка меню была всегда: в [@BotFather](https://t.me/BotFather) →
  `/setmenubutton` → выбери бота → пришли `WEBAPP_URL` и название кнопки.

## Как это работает

1. **Меню** — блюда по категориям, поиск, фильтры, кнопка 🎲 «что сегодня поесть».
2. **Карточка блюда** — КБЖУ на порцию, состав с граммовками, шаги, плюсы/минусы,
   предупреждения о проверке маркировки. Порции пересчитываются (1–8).
3. **План еды (корзина)** — выбранные блюда с числом порций.
4. **Оформление** — создаётся план, автоматически собирается **список покупок**
   (одинаковые ингредиенты объединяются и группируются: мясо, овощи, крупы…).
5. **Уведомление** — второй член семьи получает в Telegram сообщение с составом плана.
6. **Заказы** — история планов, смена статуса, кнопка 🔁 «повторить».

### Контроль глютена

Каждый ингредиент имеет статус: `SAFE`, `CERTIFIED_GF_REQUIRED` (нужна маркировка
gluten-free), `UNKNOWN` (проверить состав) или `CONTAINS_GLUTEN`.

- Блюдо с ингредиентом `CONTAINS_GLUTEN` **автоматически исключается** из меню.
- Ингредиенты `CERTIFIED_GF_REQUIRED` / `UNKNOWN` помечаются значком ⚠️ в составе и в
  списке покупок («проверь маркировку»).

### Углеводная нагрузка (ГСД)

Показатель на порцию: 🟢 низкая / 🟡 умеренная / 🔴 высокая. Если углеводов на порцию
много, статус блюда автоматически понижается с «подходит» до «периодически».

## Команды

```bash
# наполнить/обновить базу блюдами
python seed.py

# запустить всё
python run.py

# тесты
cd backend
python -m pytest tests/ -q
```

## Структура

```
EATME/
├─ .env                  # настройки (токен, ID, URL)
├─ install.bat / start.bat
├─ run.py                # запуск сервера + бота
├─ seed.py               # наполнение базы
├─ eatme.db             # база SQLite (создаётся автоматически)
├─ backend/
│  └─ app/
│     ├─ main.py         # FastAPI
│     ├─ models.py       # таблицы
│     ├─ nutrition.py    # расчёт КБЖУ и списка покупок
│     ├─ auth.py         # проверка Telegram initData
│     ├─ api/            # эндпоинты
│     ├─ bot/            # Telegram-бот
│     └─ seed/           # ингредиенты + рецепты + валидация
└─ frontend/
   ├─ index.html
   ├─ styles.css
   └─ app.js             # Mini App
```

## Добавить своё блюдо

Открой `backend/app/seed/recipes_data.py`, скопируй любой блок `R(...)`, поменяй
поля и ингредиенты (ингредиенты бери из `ingredients_data.py`, при необходимости
добавь новые туда же). Затем `python seed.py`. Валидация глютена и КБЖУ пройдут сами.
