# Деплой EAT ME на Render (бесплатно, без карты)

Приложение работает в облаке через **webhook** (без туннеля), с постоянным HTTPS-адресом.
База наполняется блюдами автоматически при первом старте.

## 1. Залить код на GitHub
Создай пустой приватный репозиторий `eatme` на github.com (без README/gitignore),
затем из папки проекта:

```bash
git remote add origin https://github.com/<ТВОЙ_ЛОГИН>/eatme.git
git push -u origin master
```
При первом пуше откроется окно браузера для входа в GitHub — подтверди.

## 2. Развернуть на Render
1. Зайди на **render.com** → Sign up / Log in **через GitHub**.
2. **New → Blueprint** → выбери репозиторий `eatme` (Render прочитает `render.yaml`).
3. Впиши секреты (Environment):
   - `BOT_TOKEN` — токен бота
   - `ALLOWED_TELEGRAM_IDS` — `674280065,844197375`
   - `WIFE_TELEGRAM_ID` — `844197375`
4. **Apply / Create** — Render соберёт и запустит сервис.

Через пару минут получишь адрес вида `https://eatme.onrender.com`.
Бот сам поставит webhook на этот адрес и кнопку «Меню» — приложение заработает в Telegram.

## 3. Обновления
Меняем код → `git commit` → `git push` → Render деплоит сам.

## Заметки
- Бесплатный сервис Render «засыпает» после 15 мин простоя; первое открытие после паузы
  ~30–60 c (просыпается). Чтобы держать бодрым — можно добавить пинг (UptimeRobot) на
  `/api/health` каждые 10 минут.
- База SQLite на бесплатном тарифе — временная: рецепты/фото всегда на месте
  (пере-наполняются), но история заказов сбрасывается при передеплое. Для постоянного
  хранения позже подключим бесплатную базу Neon (Postgres) — переменная `DATABASE_URL`.
